# Dashboard Design

## Design Goal

Create an executive CX product that communicates the network status in seconds.

## Visual Hierarchy

1. KPI selector and filters
2. KPI card
3. Momentum Matrix
4. Executive summary
5. Region performance
6. Top opportunities and risks
7. Branch detail

## KPI Card

The KPI card contains:

- selected KPI
- dynamically colored CM value
- CM vs PM delta
- matrix code
- 12-month mini trend
- CM, PM, PPM, and target

## Matrix Interaction

The 3×3 matrix is the primary interaction. Selecting a cell filters:

- KPI summary
- charts
- opportunities
- risks
- branch detail table

## Color System

- Accelerating: teal to cyan
- Stable: dark grey to light grey
- Decelerating: maroon to red

The same colors are reused across the KPI card, matrix, and charts to create one visual language.

## Mobile-First Decisions

- compact filters
- one-line KPI name
- inline trend
- short CM/PM/PPM labels
- abbreviated matrix codes
- touch-friendly cells
